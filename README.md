# مياه العراق — خريطة تفاعلية

واجهة عربية تفاعلية لاستكشاف الأنهار والروافد والسدود والنواظم والبحيرات والأهوار في العراق.

## التشغيل
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. تستخدم الخريطة Leaflet وخرائط OpenStreetMap، وتحمّل طبقات الموارد المائية من خدمة ArcGIS المنشورة.

## محتويات الخريطة
- دجلة والفرات وروافدهما الرئيسية.
- طبقات السدود والنواظم/البراجات والمواقع الرطبة حيث تتوفر بيانات المصدر.
- مواقع إرشادية للبحيرات والأهوار البارزة.
- بحث، مرشحات طبقات، تكبير تلقائي، ولوحة تفاصيل جانبية.

## مصادر وقيود البيانات
- طبقات الأنهار والسدود والمنشآت والمواقع الرطبة: [Water Resources Iraq — ArcGIS Feature Service](https://services1.arcgis.com/0MSEUqKaxRlEPj5g/ArcGIS/rest/services/Water_Resources_Iraq/FeatureServer).
- أسماء الأنهار والبحيرات والسدود والأهوار: [الخريطة الاستثمارية للهيئة الوطنية للاستثمار](https://investpromo.gov.iq/investment-map/).
- خلفية الخريطة: [OpenStreetMap](https://www.openstreetmap.org/copyright).

تُظهر بيانات طبقة الأنهار والمنشآت في خدمة ArcGIS تاريخ تعديل يعود إلى 2019 لبعض الطبقات؛ لذلك تُستخدم كمرجع مكاني تعليمي وليست بيانات تشغيلية أو آنية. مواقع البحيرات والأهوار المضافة يدوياً علامات تقريبية وليست حدوداً مساحية دقيقة. إذا تعذّر جلب مسارات الأنهار من الخدمة، يعرض التطبيق خطوطاً توضيحية تقريبية ومتقطعة للأنهار الرئيسية مع التنبيه إلى ذلك.
