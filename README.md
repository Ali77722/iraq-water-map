# مياه العراق — خريطة تفاعلية

خريطة تعليمية تفاعلية باللغة العربية لموارد المياه السطحية في العراق.

## طريقة الاستخدام
- افتح الموقع بالإنترنت لتحصل على خلفية OpenStreetMap التفصيلية مثل النسخة الأصلية.
- بعد أول زيارة تُحفظ بيانات الأنهار والمنشآت وملفات التطبيق محلياً.
- عند انقطاع الإنترنت تنتقل الخلفية تلقائياً إلى خريطة حدود مبسطة محفوظة محلياً، مع بقاء طبقات المياه والبحث والتحديد والشرح متاحة.
- عند عودة الإنترنت ترجع خلفية OpenStreetMap تلقائياً.
- يمكن إضافة الموقع إلى الشاشة الرئيسية من قائمة المتصفح.

## ما الذي يعمل دون إنترنت؟
- مكتبة Leaflet وطبقات المياه محفوظة محلياً.
- الأنهار (84 مقطعاً)، السدود (7)، المنظمات (43)، البراجات (18)، ومواقع رامسار محفوظة محلياً كـ GeoJSON.
- البحث والتكبير وتحديد الأنهار وإبراز المسارات والشرح تعمل محلياً.
- خلفية الشوارع التفصيلية تحتاج الإنترنت؛ البديل المحلي هو حدود الدول والمدن الرئيسية فقط.
